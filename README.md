# AI-POT 1급 확인퀴즈

수업 시간에 배운 내용을 바로 확인하는 퀴즈예요.
휴대폰으로 접속해서 풀면, 점수와 순위가 바로 보여요.

**접속 주소: https://ohmycoding1.github.io/aipot-quiz/**
(수업 슬라이드의 QR 코드를 찍어도 돼요.)

## 처음 들어갈 때

1. 학번, 이름, PIN(비밀번호, 숫자 4자리)을 입력해요.
2. PIN은 처음 입력한 숫자로 정해져요. 다음 수업에도 같은 숫자로 들어오세요.
3. PIN을 잊어버리면 선생님께 말씀해 주세요.

## 문제 푸는 방법

1. 선생님이 그 차시 문제를 열면 아래 **진행 중** 탭에 문제가 모두 나타나요.
2. 객관식은 보기를 누르고 **제출하기**를 눌러요.
3. 단답형은 답을 입력하고 **제출하기**를 눌러요. 철자를 정확하게 써 주세요.
4. 한 번 제출한 답은 바꿀 수 없어요. 신중하게 골라요.
5. 선생님이 정답을 공개하면 정답, 해설, 내 점수가 나와요.
6. 끝난 문제는 **지난 시험** 탭에서 차시를 눌러 다시 볼 수 있어요.

## 점수와 순위

- 맞힌 문제마다 점수를 받아요.
- 점수는 선생님이 **정답을 공개할 때** 반영돼요.
- 순위는 총점 → 맞힌 문제 수 → 빨리 답한 순서로 정해요.
- **순위** 탭에는 상위 5명만 보여요. 이름 가운데 글자는 * 로 가려져요(예: 홍*동).

## 이렇게 하면 좋아요

- 화면을 켜 둔 채로 기다리면 문제가 자동으로 나타나요.
- 틀린 문제는 해설을 읽고, 교재의 해당 쪽을 다시 확인해요.
- 다른 사람과 답을 맞추지 말고 혼자 풀어야 실력이 늘어요.

## 문제가 생기면

- 화면이 멈추면 새로고침해요.
- 그래도 안 되면 선생님께 말씀해 주세요.
