# AI-POT 1급 확인퀴즈

수업 시간에 배운 내용을 바로 확인하는 퀴즈예요.
휴대폰으로 접속해서 풀면, 점수와 순위가 바로 보여요.

**접속 주소: https://ohmycoding1.github.io/aipot-quiz/**
(수업 슬라이드의 QR 코드를 찍어도 돼요.)

## 처음 들어갈 때

1. 학번, 이름, PIN(비밀번호, 숫자 4자리)을 입력해요.
2. PIN은 처음 입력한 숫자로 정해져요. 다음 수업에도 같은 숫자로 들어오세요.
3. PIN을 잊어버리면 선생님께 말씀해 주세요.

## 문제 푸는 방법

1. 선생님이 그 차시 문제를 열면 아래 **진행 중** 탭에 문제가 모두 나타나요.
2. 객관식은 보기를 누르고, 단답형은 답을 입력해요. 철자를 정확하게 써 주세요.
   문제 복사와 답 붙여넣기는 막혀 있어요. 답은 직접 입력해 주세요.
3. 모두 풀었으면 맨 아래 **답안 제출**을 눌러요. 위쪽 **안 푼 문제 ↓** 버튼으로 빠진 문제를 찾을 수 있어요.
4. 선생님이 마감하기 전까지는 답을 고치고 다시 제출할 수 있어요. 고친 뒤에는 꼭 다시 제출하세요.
5. 선생님이 정답을 공개하면 정답, 해설, 내 점수가 나와요.
6. 끝난 문제는 **지난 시험** 탭에서 차시를 눌러 다시 볼 수 있어요.

## 미션 올리기

1. 선생님이 미션을 열면 아래 **미션** 탭에 나타나요. (진행 중 탭 위에도 알림이 떠요.)
2. 글 칸에 프롬프트 · 결과 · 답을 써요. 미션 글 칸은 붙여넣기를 할 수 있어요.
3. **파일 선택**으로 사진 · PDF 같은 파일 1개(10MB 이하)를 올릴 수 있어요.
4. **제출하기**를 눌러야 반영돼요. 마감 전까지는 고쳐서 다시 제출할 수 있어요.
5. 선생님이 결과를 공개하면 모두의 결과를 보고, 마음에 드는 작품에 ♥ 1표를 줄 수 있어요. 내 작품에는 투표할 수 없어요.
6. 올린 결과는 같은 반 친구들이 볼 수 있어요. 얼굴 사진이나 개인정보는 올리지 마세요.
7. 지금 제출할 미션은 맨 위에 나와요. 지난 미션은 그 아래 사진 카드로 모여 있고, 눌러서 다시 볼 수 있어요.
8. 결과 사진을 누르면 크게 보이고, 그 화면에서 ♥ 투표를 해요. 하트 수는 사진 오른쪽 아래에 보여요.
9. 선생님이 고른 우수 작품에는 🏅 포인트가 붙고, 그 점수는 순위에 더해져요.

## 수업 자료 받기

1. 아래 **자료** 탭에 선생님이 올린 자료가 차시별로 모여 있어요. 새 자료가 올라오면 탭에 숫자가 떠요.
2. **받기**를 누르면 파일이 내려받아져요. 파일이 화면에 열리기만 하면 길게 눌러 저장하세요.

## 점수와 순위

- 맞힌 문제마다 점수를 받아요.
- 우수 미션으로 뽑히면 🏅 보너스 점수를 받아요.
- 점수는 선생님이 **정답을 공개할 때** 반영돼요.
- 순위는 총점 → 맞힌 문제 수 → 빨리 답한 순서로 정해요.
- **순위** 탭에는 상위 5명만 보여요. 이름 가운데 글자는 * 로 가려져요(예: 홍*동).

## 이렇게 하면 좋아요

- 화면을 켜 둔 채로 기다리면 문제가 자동으로 나타나요.
- 틀린 문제는 해설을 읽고, 교재의 해당 쪽을 다시 확인해요.
- 다른 사람과 답을 맞추지 말고 혼자 풀어야 실력이 늘어요.

## 문제가 생기면

- 화면이 멈추면 새로고침해요.
- 그래도 안 되면 선생님께 말씀해 주세요.
